1. Download clangd 19.1.2 from https://github.com/clangd/clangd/releases/download/19.1.2/clangd-linux-19.1.2.zip.
2. Find the executable file and copy it to: `./static/clangd/clangd_19.1.2/bin/clangd`.
3. Set the permission of the executable file to be executable: `chmod +x ./static/clangd/clangd_19.1.2/bin/clangd`.
